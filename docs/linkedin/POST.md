## Post body (paste into LinkedIn)

Built a full-stack hospital management portal — Meridian Health.

Not a landing-page mock. A working multi-role system where patients, physicians, nurses, and administrators share one product, with real write paths from care → chart → pharmacy → billing.

What it covers
• Patient: appointments, results, medications, messages, billing
• Doctor: day board, patient chart, labs/Rx, inbox, clinic hours
• Nurse: census, vitals, MAR, notes, shift handoff
• Admin: wards, lab queue, pharmacy stock, inventory restock, equipment service, leave review

Technical highlights
• Next.js 16 · TypeScript · Prisma · MongoDB (replica-set transactions)
• Auth.js with role-scoped APIs and assignment-based access
• Care events create invoices (visit complete / discharge)
• Expanding-circle portal entrance into sign-in

Portfolio demonstration with seeded fictional data — built to show hospital workflows end to end, not a production clinical system.

Repo: https://github.com/Salar11111/HMS-01

Happy to walk through the architecture or demo any role live.
